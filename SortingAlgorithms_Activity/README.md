# Sorting Algorithms Activity

## Program Description

kani nga program kay ga pakita sya og tulo ka algorithms sa pag sorting sa java: Bubble Sort, Selection Sort, og Insertion sort.

And iyahang purpose ani kay mag arrange sa number gikan sa pinaka-gamay hantud sa pinaka-dako nga numero, nag gamit dayun ko og separate copy sa katong iyang original na array para magparehas ang number sa each sorting algorithm.

## Sorting Algorithms

### 1. Bubble Sort

Una sa tanan kay ang Bubble Sort, mao ni pina ka sayun sabton sa tulo kay ang magkasunod na numero like ang una na number mas dako kaysa sa ga-sunod niya, mag baylo dayun sila og position hantud na ma plastar ang number gikan sa gamay paingon dako and tanan na number.

### 2. Selection Sort

Ang Selection Sort dayun kay mangita sya sa pinakagamay na number sa wala pa ma sort na part sa array. ga ibutang niya ni sa sunod nga saktong position hantud mahuman ang pag arrange. 

### 3. Insertion Sort

Ang Insertion Sort magkuha og usa ka numero ug ibutang niya ni sa sakto nga position tunga sa mga numero nga na-sort na.

## Differences Between the Algorithms

- **Bubble Sort:** Ga compare ug ga swap sa gasunod nga number.
- **Selection Sort:** Gapangita sa una og pinakagamay na number before e sort or ibutang sa sakto na porsition.
- **Insertion Sort:** Kani dayun ga insert sa number sa sakto nga lugar, like sa tunga sa number nga sorted na.

## Reflection Questions

**1. Unsa ang kalainan sa Bubble Sort, Selection Sort, ug Insertion Sort?**

Ang Bubble Sort nag-compare sa magkasunod nga numero, ang Selection Sort mangita sa pinakagamay nga numero, ug ang Insertion Sort magbutang sa numero sa sakto nga position.

**2. Asa sa tulo ka sorting algorithms ang pinakasayon para nimo? Ngano?**

Para nako, ang Bubble Sort ang pinakasayon sabton kay simple ra ang process. I-compare lang ang duha ka magkasunod nga numero ug mag-swap dayun og kinahanglan.

**3. Asa nga sorting algorithm ang mas maayo kung ang array hapit na ma-sort? Ngano?**

Ang Insertion Sort kay dili na kaayo kinahanglan og daghang pagbalhin kung hapit na mahan-ay ang mga numero, kay iya raman tung birahon ang number na kaylangan isuksok sa tunga sa na arrange na, so mas okay ni sya gamiton ana na sitwasyon compare sa uban. 

**4. Unsa ang mahitabo kung mudaghan ang numero sa array?**

Kun mudaghan ang numero, mudaghan pud ang comparisons ug proseso nga buhaton sa sorting algorithm. Tungod ani, mas madugay ang iyang pag-sort.

**5. Ngano importante nga makat-on ta og lain-laing sorting algorithms?**

Importante jud kaayo ni pag masabtan nato kun unsaon ang pag gamit sa lahi-lahi na sorting algorithms kay dako kaayo iyang matabang para sa pag arrange or pag han-ay sa data og para sad nga maka pili tag tarong nga algorithm depende sa sitwasyon og unsay gipa code.
